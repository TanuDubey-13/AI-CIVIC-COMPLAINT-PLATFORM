# AI Civic Complaint Platform

This workspace now includes a starter structure for:

- Frontend React application under client/
- Backend Node.js server under server/
- AI service under ai-service/
- Database schema and sample data under database/
  

## Getting started

1. Install frontend dependencies in client/
2. Install backend dependencies in server/
3. Start the backend with npm start or node server.js
4. Start the frontend with npm run dev
